# RC-Simple 第二轮 · 设计与操作变化

以 v0.4.0-rc.simple.1 @ f81f49ee 为程序基线，工作区起点 098fe891。仅修改 WPF、视图模型显示文案、原生定向验证与交付工具，未修改 Core/Data、Schema4、知识包、统计事实及迁移。

| 操作 | 第一版 | 第二版 |
|---|---|---|
| 开始日常学习 | 科目 → 可选章节 → 开始 | 同样步骤；任务管理移至次级菜单，迷你窗移至卡片标题轻入口 |
| 保存后继续 | 上一段数字 + 开始学习 | 标注“上一段已保存 · 有效学习时间”，按钮“开始下一段”；快照和数据库不清零 |
| 改/删今日记录 | 每行查看/编辑/删除三个按钮 | 查看详情保留直达；记录操作 → 编辑/删除（多一次菜单，减少误触，危险删除仍确认） |
| 更新章节进度 | 顶部范围/应用目录 + 科目更新 | 直接看到三科摘要与更新；设置/目录移至下方展开项，保存步骤不增加 |
| 看时长 | KPI 下先遇多个高级入口 | KPI → 趋势/科目分布 → 历史记录 → 单一详细分析 |
| 高级统计 | 章节/自定义/口径/热力多个展开项 | 统一“详细分析”，内含筛选、口径、热力和章节/复盘；切换不再强制滚回页首 |

保留三主导航与更多功能，不增加模式开关。进度空字段不占空行；完整树/搜索、知识包、独立进度保存、旧任务编辑、薄弱点、日历、历史修订、片段操作、备份恢复均保留。

重要文件：MainWindow.xaml（页面与菜单）；MainViewModel.Focus.cs（完成态显示）；MainWindow.Presentation.cs / .xaml.cs（共享记录处理器接受 MenuItem）；SimpleProgressWorkspace.xaml（摘要与次级设置）；SimpleInteractionValidation.cs（隔离 HWND 验收）；Package-Simple2.py（新版本独立封包）。

Skill：读取 yanji-domain-rules 约束原始时长/事务；读取 ui-ux-pro-max 并实际运行 `search.py "keyboard focus" --stack wpf -n 2`，采用键盘可达、MVVM 与仅视图逻辑的 code-behind。结合 receiving-code-review 核对完成态原理，不将反馈误判为计时故障。未安装新依赖，没有调用 Web 设计引擎。
