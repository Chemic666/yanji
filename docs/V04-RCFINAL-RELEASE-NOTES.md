# GitHub Release 草稿：YanJi V0.4.0 RC-Final

**仅准备，未推送、未上传资产、未公开发布。** 版本0.4.0-rc.final.1，预发布候选；不是V0.4.0 Stable。

研迹面向考研日常学习，把知识目录、任务、专注计时、学习记录、薄弱点与投入复盘连成一体。Windows 11 x64，离线优先，无强制账号、服务器或云同步。

## 当前功能

- 多级知识节点、搜索、进度与掌握独立管理，稳定ID关联历史记录。
- 纯数据知识包安装、预览、版本差异、三方冲突保护与安全回滚。
- 自由计时、倒计时、番茄钟、暂停、迷你窗和托盘；任务/节点一键开始、最近继续。
- 原始学习记录修订、软删/恢复、片段排除、跨日统计与下钻。
- 薄弱点关联、章节投入、完整备份/校验/恢复、CSV导出。

## 本候选修正

原创代码正式采用Apache-2.0；根LICENSE、NOTICE、版权边界、完整第三方清单及嵌套MIT材料随适用发行物提供。修复构建/打包遗漏，新增轻量许可门禁及负例；更新陈旧README、候选版本信息和启动探针的数据目录证据。未扩展学习功能、改变Schema或重写计时系统。

## 安装、升级与数据

完整解压到新的可写目录，双击YanJi.exe，无需.NET SDK。旁置data-rc-v04与旧版隔离，先看START-HERE.md和USER-GUIDE.md。不要覆盖正式安装。

升级只支持通过严格校验的声明结构，不能保证所有历史版本直接升级。升级前创建并校验完整备份；按UPGRADE-ROLLBACK.md复制升级到新目录，回退用升级前原格式备份，不让旧程序直接写新版Schema。回退旧快照不合并之后新增学习。真实用户数据库升级尚未授权。

知识包元数据当前CC0-1.0，外部资料不因此获得授权。408含145个参考目录节点，不是官方年度完整大纲；其他基础模板的适用范围见KNOWLEDGE-SOURCES.md。

## 验证与限制

源代码、程序集、Tag和ZIP哈希按外部release-manifest.json核查；每包内部manifest-sha256.json列文件SHA。公开页面应从随包SHA256SUMS.txt填入实际摘要，不使用占位哈希。

程序未进行代码签名；SmartScreen实际表现未验证。未完成的物理IME、其他物理DPI、干净Windows离线、电源与多日稳定性必须保持NOT TESTED。有限后台观察不等于完整应用长期认证。最终本机验收结果见候选验证报告及证据包，不能以自动化数量代替数据正确性或用户验收。
