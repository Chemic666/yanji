# 研迹 V0.4 RC-Final 使用说明

这是待最终人工验收的Windows 11 x64候选版，不是公开正式版。无需账号、服务器或.NET SDK。

## 启动与数据

完整解压Windows ZIP到可写的独立目录，双击 **YanJi.exe**。本候选版默认将数据保存在程序旁的 **data-rc-v04**，不接管旧版正式目录。不要只复制EXE，不要将程序放在禁止写入的位置。换目录前先导出完整备份，不能把删除程序目录当作安全卸载。

首次弹窗可设置2028入学考试档案、日期及日常科目；日期可空，取消也可先使用默认配置。在「设置与数据」可再次配置。暂不使用科目通过归档隐藏，历史记录、节点和知识包保持。

需要指定独立数据目录时，CMD可运行：

```cmd
YanJi.exe --data-dir "D:\YanJi-RC-TestData"
```

本轮仅验收合成数据。接入真实学习数据必须另获升级授权；不要把RC直接覆盖到正式安装或旧数据目录。

## 每日流程

「计划与进度」可浏览、搜索知识目录，并从节点开始学习或新建绑定任务。「今日学习」的待办与最近学习可直接开始新一段。

自由计时显示有效时长，倒计时/番茄显示剩余时间，均为HH:mm:ss。暂停与番茄休息不计入学习。主窗与迷你窗共享状态；活动计时点击X进入托盘，明确退出可结束保存或暂停退出。未知时间须核对，不自动补算。

结束后已经保存，可跳过备注、薄弱点和学习状态补充。完成任务、已学习、自评掌握、验收通过彼此独立，不由时长自动判断。

补录只必填日期、科目、时长，可选节点/任务。纯时长无时间位置。修改已有事实请用编辑，不要重复追加。

## 查看与修正

统计的日期、科目和章节入口可回到原始记录；知识详情展示自身/含后代时长、次数、最近日期及相关记录。父级已含后代，不能再把父子时长相加。未关联节点的科目学习时间单列。

记录可编辑、软删除、恢复，片段排除与恢复保留修订。主要节点使用稳定ID；后来的任务改绑、节点改名/移动不会改写当时的路径与任务快照。薄弱点可关联、解绑、编辑及独立验收。

内置408为145节点原创参考目录，其他模板为基础参考，不是官方2028考试大纲。导入/更新先看差异，再确认冲突；默认保留个人修改，不按同名节点合并身份。

## 备份

设置页「导出完整备份」生成.yanjibak并校验。CSV用于查看，不能代替完整备份。恢复为整体替换，不合并；先校验并自动保留当前完整备份和回退副本，活动计时须先处理。优先将备份复制到独立存储位置；本轮不会自动删除备份。

旧版升级与旧格式回退见 `UPGRADE-ROLLBACK.md`。真实电源、物理输入法、其他系统DPI和干净机仍需人工验收。
