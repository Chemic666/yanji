# RC-Polish.2 · 隔离试用

完整解压新目录，双击YanJi.exe。默认数据为本程序旁data-rc-polish2；不要覆盖旧版程序或选择真实数据库/备份。

- 无活动计时：×、Alt+F4、任务栏关闭均退出；感想先保存，未保存章节编辑会提醒。保存失败保持打开。
- 有活动计时：选择结束并保存后退出、继续后台运行、取消。继续后台时保留秒数与15秒防丢检查点，从托盘或迷你窗返回。
- 迷你窗：Ctrl+M或今日入口打开；拖动面板移动、记忆位置，可置顶；悬停/Tab显示按钮，×和Esc只隐藏迷你窗。半透明纯色材质，不做动态模糊或鼠标穿透。
- 知识包：学习进度→完整知识目录→知识包（或更多功能→参考目录与知识包）。默认全部科目，可见数学一/二、408、英语一/二。所有目录是参考整理，并非2028官方完整考纲；英语模块不强制安装。已安装仍显示，可查看目录；安装/更新继续预览和确认，保护本地修改。
- 单行Enter保存；多行Enter换行/Ctrl+Enter保存，组合输入期间不提交。物理微软拼音仍需人工确认；搜索不会提交。
- 大数字每秒变化；汇总在暂停/结束/明确修改后刷新，15秒保存不再整页重建。

约5分钟人工复核：新目录运行，开始→关闭→取消；再关闭→后台，从迷你返回；最后关闭→结束保存，确认进程退出。输入中文候选Enter先确认候选，之后Enter/Ctrl+Enter保存；拖动迷你窗，在自己的浅/深背景上核对可读性。全程使用此隔离候选库。
