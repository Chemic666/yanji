# RC-Polish · 隔离试用

完整解压到新的可写文件夹，双击 YanJi.exe。不要覆盖 RC-Simple.2；默认数据位于本候选程序旁 data-rc-polish，不要选择真实学习库或真实备份。

- 正常流程仍为：选科目 → 可选章节 → 开始 → 暂停/结束。大数字 HH:mm:ss 每秒刷新，迷你窗口共享状态。
- 汇总/列表/图表在暂停、结束及其他明确数据操作后刷新；约15秒后台防丢检查点仍保留，保存检查点不再整页重建。跨日及异常状态仍按原规则处理。
- 单行文本 Enter 保存，多行 Enter 换行、Ctrl+Enter 保存。章节搜索、下拉候选、只读文本不触发保存。知识树名称/描述与日常编辑共用组合输入保护。
- 主要编辑表单提交期间显示“保存中…”，禁止重复提交；校验或写入失败保留内容；成功后显示“已保存”。独立进度不增加学习时长。删除、历史、备份恢复仍按原入口操作。

建议人工检查（约5分钟，全部使用本隔离库）：
1. 在单行章节名用微软拼音输入中文，候选窗中按Enter应只确认候选，第二次Enter才保存。
2. 在进度/备注多行框输入两行，Enter应换行；选完中文候选后Ctrl+Enter保存。IME组合期间Ctrl+Enter不得误提交。
3. 用Tab走查保存/取消与菜单，确认焦点可见；搜索框Enter不应提交。
4. 悬停/按住按钮检查反馈，切换浅深主题；用临时科目计时约1分钟、暂停/继续/结束，核对主/迷你窗口与汇总。
