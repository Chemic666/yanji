# YanJi V0.4.0 RC-Simple（本地候选）

版本0.4.0-rc.simple.1；未公开发布，未升级真实用户数据库。

- 三个日常页面：今日、学习进度、学习数据；完整知识树/任务/薄弱点/历史审计及设置继续保留。
- 默认自由计时，大数字秒级更新；补录、可选章节与今日记录就近可达，番茄钟与倒计时次级展开。
- 独立保存“学到哪里/下一步”，与明确学习状态一起原子提交、保留历史；无需先计时，不自动推断掌握。
- 数学/英语参考包1.1完善且可切换适用范围，同一安装共用节点；408同包由145增至177，原外部ID保留、三方更新保护本地修改。
- 新档案可选择直接应用三科预设；已有目录不会静默覆盖，旧包及恢复点保留。

Windows 11 x64自包含，完整解压后双击YanJi.exe，数据默认旁置data-rc-simple。使用方法见START-HERE.md；Schema4与旧格式备份/回退规则保留。用户数据不会因开源而上传。程序未签名，SmartScreen、物理输入法、其他物理DPI、干净机离线及电源测试仍需如实人工验收。

源代码与Windows程序集的准确提交、标签、ZIP CRC与逐文件SHA见随包外部release-manifest.json和SHA256SUMS.txt。知识包是参考学习目录而非官方年度完整大纲，来源与范围见KNOWLEDGE-SOURCES.md，原代码Apache-2.0、目录元数据CC0、第三方各自许可。

公开发布、真实数据切换和V0.5均未授权；本候选交付后停止。
