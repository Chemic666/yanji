# 研迹 V0.4.0 RC-Final

版本0.4.0-rc.final.1，Windows 11 x64，自包含、离线优先的最终人工验收候选版。未公开发布为Stable。

1. 完整解压到一个新的可写目录，双击`YanJi.exe`，无需.NET SDK或账号。
2. 首次设置2028入学考试档案和科目；日期可空。
3. 在计划与进度选择科目，安装参考知识包，从节点或任务开始学习。
4. 数据默认在程序旁`data-rc-v04`。它是候选版独立目录，不会自动打开旧版正式数据；不要覆盖正式安装，不要删除程序目录来“卸载”数据。

计时主/迷你窗显示HH:mm:ss；暂停和番茄休息不计入学习。活动计时点击X进入托盘，明确退出请用应用内退出。未知时间需要核对。

使用见`USER-GUIDE.md`，升级/完整备份/回退见`UPGRADE-ROLLBACK.md`。旧程序不能直接写新版Schema。真实学习数据库升级需要另行授权，本候选包不自动切换。
