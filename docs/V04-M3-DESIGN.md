# M3 学习闭环设计

基线458e5d6，产品代码430a67b/tag v0.4-m2.0，二者仅文档差异。M2四包外层SHA已核对；五份M0文档原样未提交。用户已授权M3自主设计/执行，High用于本次跨事务模型核查；不重复设计批准门槛。

## 单一事实与快照

- StudyRecord / sessions仍为唯一学习记录；sessions.chapter仍是唯一主要知识节点；parts仍是唯一时长事实，不另建学习记录或可写聚合。
- Schema4增量新增session_context（一条session一条context）与session_weakpoints。context列：profile_id、task_id、task_title、node_path、captured_at、capture_kind；关联弱点存稳定ID与当时标题。Context对象投影这些列，不再重复存节点ID或科目ID。
- ContextCapture：Legacy（旧版未记录开始路径）、Started、Manual、Corrected。旧记录不通过当前目录补造过去路径。档案沿节点所属档案，否则legacy-default；旧Focus任务关联保留，缺少的快照明确未知。
- 新记录首个事务里根据稳定ID捕获当前路径/任务标题；后续检查点、异常恢复和保存失败回退必须携带相同context。暂停/跨日/番茄休息计算不变。
- FocusContext保留原V0.3计时意图和旧任务字段以兼容历史；M3新任务关联只写LearningContext，Focus只保存模式/目标/休息。旧Focus中的任务身份是原始开始意图快照，编辑当前记录关联不会改写它；UI优先显示当前Context，不因解绑而回退显示旧任务。
- 任务新增可选ChapterId和ProfileId；弱点沿用ChapterId并加ProfileId。旧JSON缺字段按默认档案解码，原JSON/修订不批量覆盖。
- 新关联检查当前档案/科目/节点/任务/弱点作用域；历史与检查点只检查稳定引用和已保存的快照，不能因任务后来换科目就拒绝备份。归档节点允许历史引用，新开始需活动节点。记录修正节点/任务时重新捕获并审计；仅改备注/片段不刷新旧路径。
- 关联修改可通过再次修正撤销，revision保留前后完整记录；新增薄弱点并关联记录在同一事务中完成。学习完成、掌握、验收仍分别由用户明确操作。

## 数据边界

新库重放1→2→3→4；普通启动不升级旧库。3→4仅明确M3合成标记目录，先验证Format3完整备份，再候选事务迁移、原有事实/目录/包指纹对照、WAL检查点和原子替换；故障保留原库。1/2旧隔离实验入口提升到4。备份恢复1～4时只在候选中增量迁移；旧备份含活动计时时补上下文，使记录与检查点一致，原有效片段不变。旧M2程序拒绝4。

## 工作流与原生UI

- 知识详情：开始学习、新建绑定任务、相关记录/弱点、累计/次数/最近日期；自身/含后代分开。
- 今日任务：一键开始带任务节点；未指定节点清空旧选择，避免残留关联。最近学习按稳定作用域取最近记录，显式处理已归档节点/已完成任务。
- 结束保存：立即落盘，无强制弹窗；非阻塞补充区可选备注/薄弱点/进度，可全部跳过。自由/倒计时/番茄完成统一触发。
- 补录加可选任务；保留纯时长，未指定节点归入未关联。记录详情显示开始时路径与当前路径，提供知识目录跳转、当前关联修正/历史与弱点入口。
- 延用Quiet Focus，1200×800/900×600、双主题、实际200%DPI；知识树与统计自有异步状态，不占用主计时Busy。

## 统计

对根及所有后代取ID集合；筛选有效、非软删记录和日期内原始parts；Part.Id去重后聚合毫秒，最后格式化整数秒。次数按有有效贡献的Session.Id去重；最近日期来自part.Date。父子多选取并集；自身与子树数值不能相加当总计。未指定节点单列，不消失。修改/软删/恢复/排除片段后重新查询同一事实。薄弱点/任务状态不由时长推出。

本阶段不做M4真实数据升级/正式发行、V0.5错题/模考/评分，也不做账号/云服务。
