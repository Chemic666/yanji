# 澄境原始视觉还原 · RC quiet.2

## 视觉基准纠正与范围

本轮以用户确认的原始 `design/quiet-focus-2/concepts/A-inspiration.png` 为主要基准。其窗景、自然光、半透明主面、中文宋体标题和左钟面/右操作构图具有优先性。历史 DESIGN.md 与 QUIET-FOCUS-2.md 描述的简化纯色原型保留为历史资料，不代表本轮的完整还原标准。

只改今日与迷你窗提示层，不改学习进度/学习数据主要结构、数据库/Schema4、计时核心、原始毫秒、知识包/稳定ID、备份/恢复、应用图标及许可声明。

## 设计规范

- 自然光：单张内嵌静态房间图，暖象牙白、右侧窗景与植物；浅色不透明度0.90，深色0.22。今日“光景”菜单可选自然光、柔和光、纯色；仅当前窗口有效。系统高对比度时关闭图片并使用系统色。
- 标题：SimSun → Microsoft YaHei UI 系统回退，38/32 DIP，正常字重；副标题16。没有分发字体或苹果素材。WPF没有通用字距属性，不用逐字控件拼接；以字体度量、行距和留白还原书卷气。
- 数字：Georgia → Cambria → Segoe UI，104/88 DIP、等宽数字，DownOnly Viewbox避免长小时数溢出；HH:mm:ss来源与原程序一致。
- 布局：1200宽标题与今日/本周汇总并排；主面板留出72 DIP右侧光景；900宽汇总落到标题下，面板占满内容宽，感想/下一任务上下排列，纵向滚动。不是整页缩放。
- 主面：20圆角，浅色#CCFFFFFA、深色#E527342D，细高光与静态偏移阴影。文字不降低透明度。没有动态模糊、实时背景采样或周期重绘任务。
- 操作：58 DIP主按钮，深森林绿/深色鼠尾草绿、上沿高光、轻渐变、2 DIP按压、可见键盘焦点，140ms既有反馈且尊重系统减少动画。自由/番茄/倒计时用原生RadioButton分段选择；参数、备注、任务管理沿用原命令。
- 记录：仅今日采用半透明行背景；查看/修订/软删除入口保留。感想与下一任务位于记录下方。计时结束仍保留本段数字，但明确“上一段已保存”和“开始下一段”，不伪装清零。

## 迷你窗根因与修复

修复前真实 HWND 与 Windows.Graphics.Capture 均保留。布局探针发现提示与工具条重合190.5×19 DIP，工具条出现时提示仍Visible，透明底让文字透出；计时文字绑定控件只有1个。不是重复计时控件。

仅在hover/键盘焦点展开工具条时把提示Hidden（保留尺寸），工具条使用不透明内容面，外壳仍半透明。拖动、置顶、位置记忆、共享状态和关闭语义不变。其他未复现的数字残影不做无依据重构。

## 素材及 Skill 实际使用

背景是本项目通过image模型专门生成的独立室内氛围图，没有复制原概念图的UI/Logo；来源、提示词、SHA与权利边界见 `src/YanJi.App/Assets/Atmosphere/README.md`。

本会话显式读取项目 ui-ux-pro-max、redesign-existing-projects、high-end-visual-design、yanji-domain-rules，并运行 ui-ux-pro-max 的 WPF typography/material/contrast查询。采用分层构图、原生控件、系统字体回退和高对比策略；拒绝CSS/GSAP、网页玻璃滤镜和专有字体。未声称自动发现成功或运行完整设计引擎。computer-use用于真实窗口及指针状态核验；systematic-debugging用于先留存迷你窗失败证据后修复。

## 候选使用

解压整个Windows x64包，双击YanJi.exe。无需额外.NET；候选默认在自身目录的data-rc-quiet创建独立数据。请放在新目录，勿复制真实学习库。今日菜单“光景”可减弱背景。自由计时为默认；补录在主按钮下，迷你窗Ctrl+M，快捷保存规范未改变。

本轮没有正式升级用户数据。没有公开发布、推送或进入V0.5。完整实测结果与未验证边界见本轮验证报告。

## 有意保留的差异

保留Windows原生标题栏/图标，不复制概念图的虚构Logo、文案示例数值或macOS控件。背景为新生成的相似氛围而非同一照片；半透明来自静态WPF合成，未实现真实Acrylic/Mica。中文字体依赖系统回退，非逐像素一致。900窗优先可读与可操作，记录/感想需要滚动。
