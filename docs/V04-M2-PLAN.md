# V0.4 M2 实施计划与执行账本

基线：f5f189a / codex/v04-m1；M0 五份原文保持未提交，不改写。范围限知识包，不新增 M3 学习上下文、不开放正式数据升级。使用 writing-plans / executing-plans、TDD 与项目 yanji-domain-rules；项目级指导在本会话显式读取，不声称自动加载。

## 技术决策

- 原 chapters 与 KnowledgeNode 是唯一目录；知识包外部 ID 映射到本地稳定 ID，不按标题吸收旧节点。
- 新增 Schema3：版本快照、安装、节点绑定、目录操作日志；不重建学习事实表。全新数据库重放 1→2→3，旧文件仅显式隔离迁移。
- JSON 格式1：严格属性/类型/重复键检查；16 MiB、10000节点、深度32；SHA256 使用排序属性、UTF8 的规范化 JSON（排除顶层 ContentHash）。哈希校验完整性，不证明作者权威。
- 一个包安装到明确的考试档案；每个包科目键显式绑定该档案科目。安装保留请求内容/来源/许可；同版本不同哈希或来源身份变化拒绝。
- 更新按字段比较 B（当前模板）、L（目录）、U（新模板）。冲突默认保留本地，确认预览后才写。学习进度、掌握、状态不属于模板字段；备注冲突不静默覆盖。
- 删除是目录归档/解绑：有学习引用、用户修改、用户子节点者保留；无使用且无修改者可归档，永不物理删节点。
- 回滚仅最近未回滚目录操作；逆向三方比较，不恢复数据库。新增但已学习/修改/有本地孩子的节点保留解绑；学习状态与后续记录永远保留。
- 预览使用完整目录、安装、关联事实与恢复 epoch 的校验令牌；提交重新生成计划并复核，拒绝陈旧/篡改预览。应用前验证完整备份；单一事务写节点、绑定、版本、操作、修订。活动计时阻止应用。
- 原生 WPF 独立知识包窗口：模板、明确目标、结构预览、差异、逐项冲突选择、已安装/历史/回滚；后台解析和预览，自有 Busy，不冻结计时 VM。

## 执行顺序与验收

1. 格式模型与验证：真实无效输入 RED→GREEN，重复键/ID、缺父、环、类型、版本、边界、异常文本、哈希。
2. Schema3 与包生命周期：文件 SQLite，V1→本地修改→V2→冲突→后续学习→安全回滚；幂等、故障完整回滚/重试、稳定 ID、过期预览、历史引用、备份恢复/迁移。
3. 内置原创参考目录及来源：408 四模块重点；其他基础参考与自定义空包；不复制教材/讲义。
4. WPF 窗口与交互：1200×800/900×600、双主题、中文/键盘、导入异常、冲突及回滚、计时持续刷新。
5. 最终必要回归、一次独立代码审查、单份自包含发布与归档校验；不生成重复运行副本，不清理历史证据。
