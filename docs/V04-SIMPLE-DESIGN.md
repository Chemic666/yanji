# RC-Simple · 默认简洁，按需展开

三个主要目的地：**今日**用于执行与补录，**学习进度**用于记下学到哪里和下一步，**学习数据**用于查看真实投入。第四项“更多功能”保留历史记录、日历、薄弱点、计划/任务及设置。没有简洁/专业模式，也没有第二套业务模型。

## 布局与操作

- 今日：先选科目、可选最近章节，再看HH:mm:ss大数字及开始/暂停/结束；快速补录在页首。自由计时默认，番茄钟/倒计时就近展开，备注与每日感想可选。大窗计时为主栏、今日记录为次栏，小窗纵向滚动。
- 学习进度：数学、英语、408依次展示，其他启用科目随后；每科当前章节/状态/最近学习/用户文字/下一步独立呈现。更新进度一个编辑窗完成，可按中文或完整路径搜索，最近章节优先；不要求先计时。
- 完整知识目录折叠保留，展开后可编辑、归档、移动、搜索、学习和管理知识包；该入口是完整目录，包含各考试范围及历史节点。统计和历史记录可返回同一节点。
- 学习数据：今日/本周/本月原值汇总、范围趋势与科目分布优先；自定义筛选、区间口径、热力图、章节投入与复盘展开可达，图表悬停/下钻沿用旧实现。所有统计仍来自有效StudyPart。
- “更多功能”重复点击或按Enter可从下钻页返回菜单；目录编辑、快速进度、归档和备份恢复后的摘要与展开目录相互刷新，异步刷新不抢走用户新选择。

## 视觉和组件

沿用Styles.xaml/ThemeService的Quiet Focus暖纸色、鼠尾草绿与柔和青绿，以及原浅深资源；字体用系统中文/Segoe UI，数字表格对齐。8px间距，主要操作用Primary、次要用FocusButton、补充用QuietButton，危险操作仍独立确认。大窗计时56DIP、小窗44DIP；正文14DIP左右，标题/状态/说明有明确层级。

复用NaturalDuration、StudyChart、FocusIcon、EditorDialog、KnowledgeWorkspace与原记录抽屉；新增SimpleProgressWorkspace/ViewModel负责摘要。快速进度选择器支持搜索、键盘和字段标签，所有文字可为空但章节必选；状态、进度、掌握与验收不互相替代。长路径折行并有完整Tooltip，小窗按纵向滚动读取，不横向挤压。

## 适用范围与本地内容

数学/英语类别只改变目录展示和日常选择器；未确定先看共同基础，支持查看全部。切换不创建/删除节点、不改变时长。用户自定义节点始终可访问；若它位于另一范围的模板父节点下，保留其祖先路径供访问，不把这种用户结构伪装为该类别的官方范围。旧记录/活动上下文不会因过滤而丢失。

保留既有math1/math2和english1/english2包身份，各自1.1包含共同与差异目录，同一安装内切换范围共用节点。已有两个独立变体包不会自动合并，避免改变稳定历史ID。已有科目目录不自动追加推荐包。408同包增量更新，并继续使用原三方冲突预览。
