# M3 隔离预览使用说明

这是 V0.4 M3 学习闭环预览，**用于独立数据目录，不是正式用户升级程序**。请继续保留正式版本及原有完整备份，不向本程序提供真实学习数据库或备份。

## 启动

完整解压 Windows x64 ZIP，双击 `Launch-M3.cmd`。程序自带 .NET 运行时，不需要安装 SDK。数据写入解压目录下 `m3-sandbox-data`。直接双击 EXE 会提示使用隔离启动方式，不会打开正式数据。

如自行指定新的隔离目录，在 CMD 中运行：

```cmd
YanJi.exe --data-dir "D:\YanJi-M3-Sandbox"
```

目录不可是现有正式学习目录。旧结构目录会被拒绝，不自动升级。不要启动历史 Launch-M1 / Launch-M2 文件，本审核包以 Launch-M3 为准。

## 一次学习

1. 在「计划与进度」选择知识节点，点击「开始学习」；也可在今日待办点击「开始」，自动带入任务的科目和节点。
2. 支持自由、倒计时和番茄钟。主窗与迷你窗显示 HH:mm:ss。暂停及番茄休息不计入学习，未知间隙需要核对。
3. 结束后立即保存。下方「补充本次学习」可填备注、明确修改学习状态或记录薄弱点，也可直接离开。900×600 下补充区可能需要向下滚动。
4. 最近学习快捷入口开始一条新记录，不能冒充恢复旧计时。任务已改绑时，历史节点与新任务上下文不会被混用；归档节点需要先启用。

完成计时不会自动完成任务，不会自动宣称掌握或验收。

## 补录、关联与追溯

快速补录仍只必填日期、科目、时长，可选知识节点和任务。纯时长没有开始/结束位置。已有事实请使用记录的「编辑」，不要重复追加。

记录详情显示当前节点、学习时路径、任务及薄弱点快照。点击「知识节点」返回目录，包括归档节点；「编辑整次记录」可修正主要节点和任务；「薄弱点关联」可新增或关联现有薄弱点，亦可解除现有关联而保留薄弱点本身。关联变更不会改动原始有效时长，前后内容保留在修订历史。

知识详情展示自身/含后代时长、次数、最近日期、相关任务、记录和薄弱点。父级已含后代，不要把父级和子级再相加。科目中未指定节点的时间单列。修改、软删除、恢复或排除片段后返回知识页会重新查询。

## 备份与恢复

「设置与数据」可导出、校验完整备份及恢复。恢复是整体替换，不是合并；恢复前保留当前完整回退备份，活动计时必须先处理。本阶段只用合成数据验证格式1～4兼容，不授权真实数据恢复或升级。

旧 M2 程序不能打开 Schema4。回退应使用保留的旧程序和对应旧格式完整备份，不能强行降低数据库版本号。

## 从源码构建

沿用项目 SDK 10.0.401、NuGet 锁文件与既有构建工具。发布后将 `tools\Launch-M3.cmd` 复制到发布目录再启动。正式迁移、安装器及真实用户升级入口留待 M4。
