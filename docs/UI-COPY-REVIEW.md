## 源码与编译资源检查

- `Audit-UICopy.py`生成修改前后清单：最终覆盖103个C#/XAML源文件、1790项中文文字候选，包含App/Core/Data的直接文件。它是正则提取的审查辅助，不是完整语义分析器，数量不等于逐条运行证据。
- `before/inventory.json`与`after-final/inventory.json`保留路径、行号、原文及源文件SHA。诊断Runner/Validation等文件单独分类；产品路径中剩余20项关注内容均为隔离保护、真实业务“验收”、必要格式异常或不可重写的审计文本。
- 实际编译程序集检查新成功反馈及完整恢复警告；读取真实`.g.resources`中的`mainwindow.baml`，核实备份/恢复/检查完整性等新文字存在，旧关闭说明、“整次软删除”和RC2残留不存在。
- 不宣称整个DLL不存在“测试”等字样。受显式测试参数约束的诊断代码和合成数据仍随原有程序保留，普通启动不执行这些入口。
- `change-scope-final.json`核对数据目录策略、只读启动门禁、计时核心、跨日核心及版本配置未变；数据层唯一修改是异常文案。9个相关C#文件剥离字符串后的内容与基线相同，两个XAML的元素结构和非文字布局/样式属性相同。

## 兼容、限制与后续

- 本轮没有修改RuntimeLocation、启动只读保护、Schema、迁移或时间统计规则；没有访问真实学习库，不自动导入候选数据，不自动升级。
- 正式模式标题与版本通过同一生产函数及实际程序集验证；所有真实窗口截图来自隔离模式，没有为了截图连接正式用户目录。由此不声称正式用户数据实机启动已测试。
- 保留此前数据目录“PASS WITH LIMITATION”范围；未执行物理IME、睡眠/休眠、其他系统DPI、干净Windows离线、SmartScreen或数小时耐久复测，不推断这些已通过。
- 本轮不重新执行恢复覆盖操作或知识包升级生命周期；它们的实现未改变，复用既有业务证据，恢复提示另做源代码、单元及编译内容检查。
- 之前关于素材再分发权利、公开仓库目标、历史身份信息隐私及最终发行渠道的待确认事项仍有效；没有推送、创建Release或最终标签。
- 完成本轮后停止。待下一轮公开发行审核，不继续视觉改造或V0.5。

最终源码commit、程序集SHA及构建输入闭合关系在候选ZIP的BUILD-INFO.json和build-inputs.json中；交付目录SHA256SUMS.txt核对所有ZIP。测试数据库、备份、PDB及临时截图不加入源码Git提交。
