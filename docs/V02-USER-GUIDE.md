# 研迹 YanJi V0.2 使用说明

完整解压 YanJi-v0.2.0-win-x64.zip，双击文件夹内的 YanJi.exe。不要只复制 exe。无需 .NET SDK 或账号。现有机器可直接启动 `D:\Projects\yanji\releases\YanJi-v0.2.0-win-x64\YanJi.exe`。

## 升级与数据

先用当前旧版设置页导出完整备份并校验，退出当前旧版，再启动 V0.2。两版默认使用同一个 `%LOCALAPPDATA%\YanJi` 数据目录；升级不迁移数据库结构，不附带测试数据。保留旧版程序和备份，便于回退。不要同时用两版处理同一数据。

旧版生成的隔离数据库及完整备份已用实际程序验证兼容；此验证没有访问你的实际学习记录。本轮未改变数据库结构，保留旧版程序和备份，日常使用新版。

## 每天记录

1. 今日学习中选科目，章节与备注可空，点击“开始”。暂停不计时；“暂停 / 继续”切换状态，“结束”保存。
2. 忘记计时，点击“＋ 快速补录”或 Ctrl+N，仅日期、科目、分钟数必填。例如 0.5 分钟显示为 30 秒。归档科目和章节不作为新补录选项。
3. “区间补录”用于知道准确起止时间的情况；使用带偏移的日期时间，跨午夜按实际日期分配。已知重叠阻止保存。
4. 今日显示最近 8 条记录。点击“学习记录”或 KPI 卡片查看对应范围全部记录。写下每日感想，自动保存，也可点击“保存感想”。

追加是另一段学习；修正已有记录请使用“编辑”。同日同科目纯时长补录会提示潜在重复，不会擅自扣减，也不会生成假的时间位置。不要求连续打卡。1～3 分钟是设计目标，未做真实用户耗时验收。

## 明细、修订、删除与恢复

“学习记录”可按日期、科目、章节、来源和记录状态筛选。图表点击科目、日期或周期会进入相应明细；章节投入的筛选会在编辑和刷新后保留。每行显示范围内贡献与整次时长，跨日记录仍是一次学习。

“查看”打开详情层，展示备注、有效片段、已排除片段和前后修订。“编辑”支持保留原始片段只修改科目/章节/备注，或明确改成逐日纯时长、准确时间区间。历史保留修正前事实；不会把新总时长伪装成片段删除。活动计时必须先结束才可修正。

“删除”显示科目、整次时长、全部受影响日期和片段数。确认后软删除整次，所有日期与统计同步扣除，历史仍保留。筛选“已删除”或“全部状态”，点击“恢复”重新检查时间重叠后恢复整次。

详情内“排除片段”只移除选中的原片段，其他片段与整次身份保留。已排除部分不参与统计，可用“恢复片段”恢复原日期、区间与毫秒。最后一个片段不允许排除，请软删除整次。已删除整次须先整次恢复；恢复与其他记录重叠会被拒绝，不会部分恢复。Esc 关闭详情层。

## 历程与统计

热力图展示学习时长，悬停查看精确值；边框标识待核对，− 标识明确休息日。零记录默认“尚无记录”，可以显式切换休息日标记；标记不改变既有学习事实。

选择日历日期查看当天时间轴与感想。时间轴仅显示准确区间，纯时长补录单列。跨日学习展示本日贡献和整次时长。完整记录可展开，也可打开明细。

统计可选今天、本周、本月、近 30 日或最多十年的自定义范围，并联动科目。环形、每日科目堆叠、周/月趋势、热力图及章节投入均来源于有效片段。完整周期外部分不纳入。左右/Home/End 选图表点，Enter 打开原始记录；悬停提供原始毫秒。环形中心约数以 ≈ 标识，悬停可看精确总值。

“已过自然日均” = 范围内截至今天的有效时长 ÷ 范围内已过自然日数（含今天）；未来日期同时从该分子和分母排除。“学习日均” = 整个范围有效时长 ÷ 有有效学习记录的日期数。两者明确分开；不由图形面积或归一化比例代替时长。

## 计划、薄弱点与主题

计划页以科目分组展开章节；现有模型没有章节父子关系。章节完成百分比与掌握状态分别编辑，时长增加不会自动标记掌握。已引用科目/章节使用归档，保留历史。任务完成不是实际学习记录。

薄弱点可搜索并按科目/状态筛选，查看困难、错误分类、章节、复习日期及历史。沿用待复习、巩固中、已验收三状态；没有新增复杂错题附件、模考或 AI。

设置分为考试档案、主题、计时、数据。可切换浅色/深色并保存偏好。900×600 下侧栏折叠为图标、内容转单列；图标有提示。年度热力图可横向滚动。

## 退出与待核对

活动计时点击 X 会隐藏至系统托盘并保持原状态；双击托盘可打开。“退出应用”才提示结束保存、暂停退出或取消。写入失败时保持应用打开。锁屏不自动停止学习。

重启、异常电源或时钟证据会使不确定时间进入待核对。仅保留成功确认的前缀，不自动加入休眠和未知尾部；可只保留已确认部分，或补记你确认学过的时长。核对后保持暂停。

默认约 15 秒检查点，可选 2/15/60 秒；受调度和磁盘影响，不保证固定实时保存周期。真实睡眠/休眠/Modern Standby 仍待设备验收。

## 完整备份与恢复

设置页“导出完整备份”生成新的 .yanjibak，不覆盖同名已有文件。每天首次打开自动在数据目录 backups 留下快照，不自动清理。建议定期把备份另存其他磁盘；同盘备份无法抵御磁盘损坏。

恢复前结束活动计时，选择文件，可先“校验备份”，再“恢复完整备份”确认整体替换。恢复前完整备份当前数据，并保留旧库副本；不合并两份数据。校验 ZIP、哈希、结构、版本、引用和记录内容，损坏或超过 512 MiB 的备份会被拒绝。含活动计时的备份恢复为暂停或待核对，不补算备份后的时间。

需要回退时，用恢复前生成的完整备份恢复，再核查明细与总计。不要运行时复制单个 SQLite 文件代替备份，也不要手动删除 WAL/SHM。“数据库检查”保留；CSV 导出有效分日片段用于分析，不能代替完整备份，不支持 CSV 导入。

本地库与备份未加密，按个人文件保管。程序不上传学习数据。

## 验证边界与后续

实际 WPF 渲染、自动化按钮/焦点、中文文本持久化、双主题与隔离数据安全已检查。物理键盘全流程、中文输入法候选窗、实际跨屏 DPI、真实电源/时钟变化、物理断网和干净机运行仍 NOT TESTED。详见 V02-VALIDATION.md。

后续可选：补设备验收、备份保留策略、更细的章节树、更多快捷键、复盘模板。云同步、AI 和复杂错题库需要另行确定范围。


V0.2 采用Quiet Focus暖纸/柔绿统一排版，今日左侧计时与感想、右侧账本；窄窗转纵向。统计先读自然时长和两种分母，再看每日投入与科目组成。原生悬停提示和键盘选点提供精确值；明细层禁用底层并循环Tab。
