# YanJi RC-Simple 2 · 隔离日常试用

完整解压 Windows ZIP 到**新的可写文件夹**，双击 `YanJi.exe`。无需安装 SDK。标题含 RC-Simple 2，合成试用数据保存在该解压目录的 `data-rc-simple`。不要覆盖第一版、正式安装或把真实数据库/备份复制过来。

1. 今日：选择科目 → 可选章节 → 开始学习 → 结束。自由计时默认；番茄钟/倒计时就在计时卡片的展开项。Ctrl+M 打开迷你窗，Ctrl+N 快速补录。
2. 保存后：数字标注“上一段已保存”，按钮显示“开始下一段”；这是上一段的有效时长，开始下一段才重新计时。保存状态和原始计时事实没有清零或篡改。
3. 今日记录：直接查看详情；“记录操作 ⋯”提供编辑、删除，删除仍需确认。完整记录页保留恢复、历史、片段排除与恢复。任务完成和解除关联在“任务操作 ⋯”，不自动完成任务。
4. 学习进度：点击科目卡片的“更新进度”，搜索/选择章节，可选写学习内容和下一步，保存即可，无需先计时。三科范围设置在下方“科目与目录设置”；完整知识树、知识包按需展开。
5. 学习数据：先看今日/周/月、趋势、科目分布，再看历史记录。“详细分析”集中提供自定义日期/科目、统计口径、热力、章节和复盘；点击图表仍可下钻原始记录。
6. 更多功能：日历、薄弱点、计划任务、设置/备份与恢复、参考目录仍保留；键盘 Tab 可访问按钮，Enter/Space 激活。

预设目录、Schema4、迁移/回退规则、备份替换和许可证沿用第一版。升级/回退见 `UPGRADE-ROLLBACK.md`，来源见 `KNOWLEDGE-SOURCES.md`。**本轮不执行真实数据升级；恢复会完整替换库，不能合并。**

人工试用建议 10 分钟：用临时科目计时数秒，暂停/继续并保存，查看迷你同步；独立更新章节内容；在记录菜单改备注；打开详细分析与更多功能；最后检查隔离备份。不要用真实数据进行删除、恢复试验。

物理中文输入法候选、其他实机 DPI、休眠/重启、干净机离线、屏幕阅读器和长期运行未在本轮验证。程序未签名；本包是人工试用候选，不是公开发行。
