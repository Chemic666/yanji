# Quiet Focus 2.0 · A「澄境」WPF 隔离候选

版本：0.4.0-rc.quiet.1。设计依据为 design/quiet-focus-2 的 A 方案；B 不参与实现。

## 启动与安全

解压整个 Windows x64 包，双击 YanJi.exe，无需安装 .NET。候选默认使用自身目录中的 data-rc-quiet，与旧候选及正式学习目录分离。也可指定 `YanJi.exe --data-dir <新的独立目录>`。

本轮未读取、复制或升级真实学习库。人工试用保持新目录，不要放入真实数据库。备份/恢复及旧版兼容见 UPGRADE-ROLLBACK.md；没有新增 Schema 迁移。

## 三个主要页面

- 今日：科目与可选章节 → 开始 → 暂停/继续/结束。模式在计时面板右上切换。快速补录位于页首，记录和感想在计时区下方。结束后保留上一段有效时间，明确标记已保存，开始下一段重新计时。
- 学习进度：连续手账呈现当前章节、学习内容和下一步，更新不要求计时。最近章节侧栏在小窗口移至下方；完整目录、知识包、范围设置保留。
- 学习数据：今日/周/月、趋势、科目分布、日历/当日详情、热力图、章节投入、复盘和原始记录均直接展示于同一滚动页面。分析范围与日历月份独立。

## 设计资源与素材

浅色画布 #F5F5F0，导航 #E7ECE3，内容面 #FDFEFA，文字 #273C32，辅助 #5E6B61，强调 #416853。深色 #1C2621 / #243129 / #29382E，文字 #E8EEE4，辅助 #ACB9AB，强调 #ABC8A2。

使用系统 Segoe UI Variable / Segoe UI / Microsoft YaHei UI，不分发字体。大标题32，窄窗今日标题28；计时72/56、等宽数字；常规14，标签11–12。导航172/142 DIP，边距32/24，双栏间距24/19，内容面圆角18，迷你窗22。

新增 StudioSurface、StudioTitle、StudioSubtitle、StudioEyebrow、StudioPrimary、StudioSecondary。主要按钮46高、次要38高，沿用 Soft Depth 模板、焦点轮廓、按压位移、140ms反馈及减少动画设置。输入框、下拉框和菜单保留原生模板。

材质来自静态色面，没有实时模糊、背景图或新增重型依赖。Compact 只改变主数据页环形图的半径、图例行距、测量高度，不改变值、统计分母、格式化及关联身份。NaturalDuration 保留原精度聚合后格式化。

未使用 AI 概念图中的照片、替代 Logo 或专有素材。既有应用图标、Apache-2.0、NOTICE 和第三方声明不变。

## Skill 实际应用

- ui-ux-pro-max：读取指导并运行本地 search.py 的 WPF 栈查询；采用异步操作、虚拟化、明确焦点等建议。
- redesign-existing-projects：据旧实机与 A 原型重排计时主/辅区、连续进度手账和数据模块，复用原命令/服务。
- high-end-visual-design：采用比例、留白、层级与克制材质，不搬用 CSS/GSAP、网页字体及高开销模糊。
- yanji-domain-rules：核对学习片段、稳定 ID、暂停/恢复、统计与备份不变量。
- computer-use：原生 Windows 窗口与交互状态检查。没有运行完整网页设计引擎。

## 与原型的有意差异

保留原生 Windows 标题栏、系统字形和 WPF 文本度量。模式用可键盘操作的原生下拉框，暂停按钮显式保留。小窗口纵向滚动；进度侧栏下移。迷你窗420 DIP，容纳完整 Windows 控件与操作，未照搬原型350宽。示例章节及待办来自隔离数据，不伪造真实事实。
