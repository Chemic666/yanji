# Beta 试用、旧版本兼容与回退

**当前Beta不提供旧版本数据库自动迁移。** 最安全的试用方式是显式隔离目录、新档案，不读取旧库。

1. 保留旧程序及原数据目录，用旧版本的完整备份功能创建`.yanjibak`并校验；不要复制打开中的SQLite主文件。
2. 将Beta ZIP解压到另一个全新目录。普通启动现在默认使用`%LOCALAPPDATA%\YanJi`，解压到新目录本身不再隔离数据！建议先隔离试用，使用`YanJi.exe --test-mode --data-dir "D:\YanJi-Isolated-Trial"`，选择独立试用目录。不把旧库直接覆盖进去，不覆盖旧安装，也不合并目录。原候选`data-rc-quiet`不会自动迁入正式目录。
3. 先用临时记录完成计时、进度和备份试用。只有后续版本提供正式声明支持的受控升级入口时，才按其说明升级；先备份、校验，再核对记录/片段数量、原始毫秒、关联和修订历史。没有入口或版本不支持时停止，不手工改Schema。
4. 新建库为Schema4；已有目录先做只读身份、版本、结构和快速完整性检查。旧格式、不兼容结构、损坏或空数据库文件直接拒绝，不自动迁移、不重建。历史隔离实验覆盖Schema1～4备份验证及受控升级，不等于授权任意真实旧库自动升级，也不保证任意历史版本直接升级。
5. 回退时关闭新版，使用保留的旧程序及其**升级前完整备份/原目录**。不要让旧程序直接打开升级后的Schema2/3/4，也不要用新数据替换旧备份。新版新增学习内容需要另行保全，不会自动回写旧格式。

恢复是完整替换，不是合并。项目内的测试备份不是你的个人备份。若失败，保留原库、备份和错误信息，暂停相关操作；不要反复覆盖尝试。
