# YanJi V0.2.3 小范围修正

基于 V0.2.2（81eea673），保留 Quiet Focus 布局。未修改数据库 schema、存储、计时、修订或备份恢复代码；仅使用 artifacts 下的隔离合成数据。

## 时长核查与显示规则

原样本四科原始时长：英语 37,209,872 ms；数学 33,911,873 ms；政治 31,808,638 ms；408 31,268,638 ms。总计 134,199,021 ms，显示为 37小时16分39秒。各科分别向下显示到秒后相加为 37小时16分36秒；各科余量合计 3,021 ms，形成 3 秒进位。

保留先聚合原始毫秒、再格式化的规则。各科标签不分配额外秒数，环形图与排行显示余量说明。实际非零且不足一秒显示“不足 1 秒”；自然日/学习日平均使用相同显示阈值，原始平均值不被修改。零仍显示“0 秒”，计时器原规则不变。

## 修正范围

- 1～14 日热力图使用填满可用宽度的紧凑日期条，7 日以内一行，14 日两行；真实日期保留点击入口和状态。
- 趋势及堆叠图纵轴采用自然时长，悬停仍按整数秒显示；极短值避免重复零刻度。
- 复盘增加所选日期/科目范围的有效时长、学习日、记录数。到期薄弱点与未完成任务另列为当前快照，明确不表示本期变化。无学习成果或掌握程度推断。
- make-interfaces-feel-better 本地指导用于单位换行、短范围密度与点击区域。本会话是手动读取指导，未声明自动加载或运行完整设计引擎。

## 验证范围与边界

按用户“减少不必要的测试”要求，不重复旧版全面视觉矩阵、计时故障和备份实验。已有一次 89 项核心回归通过；最后追加 7 项显示/平均值定向测试通过，其中 3 项与前次重叠。保留失败和中断结果，不改写为通过。

最终发布程序只执行 8 项针对性 WPF/数据联动检查，并生成最多 12 张真实 HWND 截图：1200×800、900×600、浅深主题、单日/周/两周、极短与空数据、复盘摘要及实际悬停。每张关联最终程序哈希和隔离数据范围。实际 DPI 以截图元数据为准；不能推断其他 DPI、中文输入法或全键盘流程已重新验证。清洁机器离线运行、真实电源恢复及用户库升级本轮未测试；未访问真实学习数据库。

完整解压 Windows x64 自包含包，双击 YanJi.exe。升级前从旧版保存完整备份并退出旧程序。沿用默认 %LOCALAPPDATA%\YanJi；本轮 schema 未变，真实用户库兼容性未直接执行验证。
