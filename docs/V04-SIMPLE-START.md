# YanJi RC-Simple · 开始使用

Windows 11 x64。完整解压程序包到**新的可写文件夹**，双击YanJi.exe，无需安装.NET SDK。标题含RC-Simple，默认数据在该程序旁`data-rc-simple`，与RC-Final的`data-rc-v04`分开。不要覆盖现有正式安装、选择真实数据目录或复制真实备份来验收。

1. 首次填写考试档案（2028为入学年份，考试日期可空），默认数学、英语、408；参考目录选“应用至空白科目”即可使用，也可以暂不应用。
2. 在“今日”选科目即可开始。章节可选、最近使用优先；默认自由计时，番茄钟与倒计时在附近展开。暂停不累计，结束保存一次；快速补录只需日期、科目、时长，不虚构起止区间。
3. 在“学习进度”选数学一/二、英语一/二或暂未确定。点击“更新进度”，搜索/选章节，选择状态，可选写学到哪里和下一步后保存；无需先计时，不增加时长，也不自动声明掌握。
4. “学习数据”看今日/周/月、趋势和科目分布；点图表回到记录。高级统计、热力、复盘按需展开；历史记录中仍可编辑、软删、恢复及查看修订/真实片段。
5. “更多功能”包含日历、任务、薄弱点和设置；知识包在学习进度的完整目录中。已有目录不会静默导入；更新时先预览差异，默认保护本地修改，勿为换考试类别安装第二套相同目录。

首次三个推荐包：数学126、英语92、408共177节点，都是原创参考目录，**不是2028官方完整大纲**。数学/英语范围过滤共用同一安装的稳定节点；完整知识目录允许查看全部范围。旧数学二/英语二包可原样保留并更新，历史独立变体不自动合并。范围及来源见KNOWLEDGE-SOURCES.md。

窗口X在活动计时期间隐藏到托盘；明确退出时选择结束保存或暂停退出。未知时间必须核对，不自动计入。Ctrl+M迷你窗，Ctrl+N补录；编辑时按字段正常输入，不要求快捷键。

设置可导出CSV、创建/校验完整备份、恢复到隔离环境。恢复是完整替换而非合并；操作前另存当前完整备份，活动计时必须先处理。旧版升级/回退见UPGRADE-ROLLBACK.md；Schema仍为4，增加的用户进度独立存储且随完整备份保留，不保证任意历史库直接打开。**真实数据升级需单独授权，本轮未执行。**
