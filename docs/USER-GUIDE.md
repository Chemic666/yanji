# 研迹 V0.4.0 Beta 使用说明

当前版本为0.4.0-beta.1，不代表Stable。程序未签名；SmartScreen、物理输入法、其他DPI、睡眠/休眠、干净机离线仍有未测项；曾观察到偶发约1秒调度停顿。

普通窗口标题为“研迹 YanJi”，侧栏显示由实际程序版本生成的简短版本信息；当前为预发布，不代表Stable。悬停版本标识可查看完整版本。隔离运行时，主窗口和迷你窗保留“隔离测试”提示。

## 开始

Windows11 x64。完整解压ZIP到新目录，核对SHA-256后双击YanJi.exe。无需.NET SDK、账号或网络。不要覆盖旧安装或直接在压缩包内运行。普通启动使用固定的Windows用户数据目录；如果仅想试用而不打开正式学习库，请使用下面的显式隔离启动方式。

首次建立档案，选择数学/英语类型或暂未确定，可应用数学、英语、408参考目录。目录非官方2028完整大纲，英语模块是复习辅助。已有目录不会静默覆盖。

## 每天三步

1. 今日页选择科目；章节、任务和备注均可不填。默认自由计时；番茄钟和倒计时在附近切换。
2. 开始学习；暂停不计时，继续后恢复。迷你窗可拖动、置顶，主/迷你状态一致。
3. 结束保存，或快速补录日期、科目与时长。手动补录不伪造起止时间。汇总在暂停/结束等数据变化后更新，不要求每15秒重建整页。

无活动计时，右上×直接退出。有活动计时，会让你选择结束保存退出、继续后台运行或取消；保存失败应保持应用打开。关闭迷你窗不结束学习，可返回主窗/托盘找回。

学习进度可独立保存当前章节、学习内容和下一步；单行Enter确认，多行Enter换行、Ctrl+Enter保存。中文候选确认应优先于提交，但物理IME兼容仍待正式验收。学习进度、掌握、验收和投入时长不是同一个指标。

学习数据页直接查看日历、趋势、科目分布、章节投入和历史记录；点击日期/科目可追溯原始记录。修改、软删除、恢复保留历史；包含多个时间片段时按实际片段处理。任务、薄弱点、知识包和修订仍可从更多功能或相关页进入。

## 本地数据与备份

普通启动默认使用`%LOCALAPPDATA%\YanJi\yanji.sqlite`，通过Windows标准用户目录API定位，不随程序移动或升级改变。不会自动搬运旧候选目录中的`data-rc-quiet`数据，也不会自动升级旧格式。已有文件异常或版本不兼容时停止启动，请保留原目录和备份。

隔离试用必须显式启动：`YanJi.exe --test-mode --data-dir "D:\YanJi-Isolated-Trial"`。请选择独立绝对路径，不选择正式数据目录、其上级或子目录，不使用目录联接。主窗口和迷你窗会显示“隔离测试”。缺少参数不会回退正式目录。所有自动化、截图和冒烟测试同样必须指定测试模式及独立目录。

设置与数据提供“备份数据”“校验备份”“恢复备份”“导出 CSV”和“检查数据完整性”。备份会生成`.yanjibak`完整快照；确认校验成功后另存到独立位置。CSV便于查看，不能替代可恢复备份。备份没有加密，注意妥善保管。

恢复前结束计时并创建/校验现有完整备份。恢复是完整替换，不是合并；确认将替换的数据后再操作。软件保留恢复前副本，但不能代替你单独保管的备份。不要复制仍在打开的SQLite主文件而忽略WAL/SHM，不要手动编辑数据库。

异常退出后仅恢复已保存的可信检查点；未知间隙进入待核对，不会自动补记。可只保留已确认时长，或人工补充明确知道的学习时间。真实睡眠和休眠仍未完成实机验收。

旧版用户先看UPGRADE-ROLLBACK.md；Beta不会自动升级旧版本学习库；不兼容时保留原文件，不手工修改结构。应用默认不上传数据，反馈问题时不要附真实数据库或备份。
