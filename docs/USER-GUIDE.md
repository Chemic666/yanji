# 研迹 V0.1 使用说明

## 启动与数据位置

完整解压 `YanJi-v0.1.0-win-x64.zip`，打开其中的 `YanJi.exe`。不能只复制单个 exe；旁边的运行时和数据库组件也需要保留。无需账号、网络服务或 .NET SDK。

正式项目中的启动文件为 `D:\Projects\yanji\releases\YanJi-v0.1.0-win-x64\YanJi.exe`。

日常数据默认保存在 `%LOCALAPPDATA%\YanJi`。设置页会显示实际位置。程序文件与学习数据分开；换发布文件夹不会自动迁移或删除学习记录。测试使用独立目录，发布包不附带示例学习数据。

## 日常记录

1. 在“今日学习”选科目，章节和备注可留空，点击“开始学习”。
2. 暂停不计入有效时长；继续后只增加新的学习时间。结束时点击“结束并保存”。
3. 忘记计时，可在快速补录填写日期、科目和分钟数，然后“追加学习记录”。这不会改变已有记录。
4. 想修正旧记录，进入“备考历程”，选日期，点击该记录的“详情 / 修正”。
5. 感想写在每日详情中，自动保存，也可点击“保存感想”。首页“查看每日详情”直接进入今天。

日常操作以 1～3 分钟为设计目标；未用真实用户操作计时验证这一目标。不强制连续打卡。

## 时间与修正

纯时长补录不会生成假的起止时间。当天已有同科目记录时会提示可能重复，请自行核对；程序不擅自扣减。

知道准确起止时间时，可选择“按明确时间区间补录”，填写包含偏移的时间，例如 `2026-10-13T08:00+08:00`。跨午夜自动按实际日期分配，仍保留一次学习的身份。已知区间重叠会阻止保存。

修正有三种方式：保留时间片段只改科目/章节/备注；改为逐日纯时长；改为明确起止时间。逐日填写格式为 `2026-10-13 = 45`，每个日期一行。选择时长修正后，原区间留在历史中，不再参与当前统计。

将记录状态改为“软删除”后不再统计；选中“包含已删除记录”，打开详情改回有效即可恢复。恢复时会再次检查区间重叠。“历史”可查看前后内容。活动计时须先结束再修正。

默认时区 Asia/Shanghai，每周从周一开始。时区变化影响新记录；历史日期和当前活动计时的时区保留原分配。

## 关闭、退出与异常

活动计时期间点窗口 X 会隐藏到系统托盘。运行中继续计时，暂停中继续保持暂停。双击托盘图标或托盘菜单可打开窗口。

明确点击“退出应用”，可选择结束保存、暂停后退出或取消。保存失败时应用保持打开，并提示核对；不要把错误提示当作保存成功。

重新打开未正常结束的运行计时，或程序发现电源/时间证据异常，会进入“待核对”。只显示已确认部分和最后确认时间。可“仅保留已确认部分”，或按日期补记自己确认学过的时长。核对后保持暂停，可以继续或结束。未知间隙不自动计入。

默认约每 15 秒保存运行检查点，可在偏好中选择 2/15/60 秒；实际调度还受到界面采样与磁盘写入延迟影响。异常退出时最后成功检查点之后的尾部需要核对，不承诺自动找回。真实休眠与 Modern Standby 尚未完成设备验证。

## 计划、章节与薄弱点

科目和章节可新增、编辑或归档。归档保留已引用记录及统计，不硬删除。章节百分比与掌握情况分别填写，不由时长推断。

简单任务可设计划日期与科目，勾选完成。任务日期不是已发生的学习事实。

薄弱点可记录知识点、错误分类、困难说明、科目/章节、后续复习日期，以及待复习/复习中/已验收状态。V0.1 不包含复杂错题附件或模考。

## 备份、校验、恢复与 CSV

在“设置与数据”选择“导出完整备份”，另存新的 `.yanjibak` 文件。程序不会覆盖同名已有文件。建议定期另存到另一块磁盘或由你管理的安全存储位置。

每天首次打开会在数据目录 `backups` 中保留当日快照。识别到损坏的同名自动备份，会保留它并另存有效备份。V0.1 不自动清理备份，因此需要定期自行管理空间。同一磁盘上的备份不能抵御磁盘损坏。

恢复步骤：结束活动计时，选择备份，可先点击“校验备份”；再选择“恢复完整备份”并确认整体替换。程序校验 ZIP、哈希、版本、结构、记录和引用一致性；恢复前完整备份当前数据并保留旧库副本。恢复不合并两份数据。备份中若带活动计时，重新进入暂停或待核对，不把备份后的时间自动计入。

损坏、版本不兼容或超过 512 MiB 校验上限的备份会被拒绝。不要在运行时直接复制单个 SQLite 文件作为备份，WAL 中可能还有已提交数据。不要手工删除 `.sqlite-wal` 或 `.sqlite-shm`。

“导出 CSV”导出当前有效记录的分日片段，带科目、章节、时长、来源、区间及备注。CSV 用于查看和分析，不包含全部历史、任务、感想和设置，不能替代完整备份。V0.1 不支持 CSV 导入。

备份和本地数据库未加密，按普通个人文件保管。程序本身不上传这些记录。
