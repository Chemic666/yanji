# 研迹 V0.2 — Quiet Focus 正式设计规范

## 事实、建议和假设

需求事实：用户确认 A 的排版与暖纸色/柔和绿，允许更好的布局；正式六页面及记录明细升级，WPF/.NET 10，不改变 SQLite、计时、修订、备份规则。本轮自主实现，不重新选择 A/B。旧正式 v0.1.1 与视觉恢复标签均保留，起点 fd12f36；新分支 codex/v0.2-quiet-focus。

设计建议：将 A 深化为学习桌式工作区，吸收 B 的紧凑日志、行内操作和筛选效率。首屏以一个主要任务为中心；减少重复标题、等权 KPI 卡和层层边框。保留原生 Windows 窗口与键盘语义。

未验证假设：此布局更适合长期备考；1～3 分钟为操作目标，不能从截图推定真实用户耗时。真实多显示器、物理输入法和系统电源实验未经授权，不用程序化结果冒充。

## 布局与组件

- 导航：常规184 DIP文字侧栏，900 DIP窗口收为72 DIP图标轨道。文字始终有清晰对比；未选中、hover、selected、disabled和键盘focus分别有静态反馈。六模块加独立记录入口，无虚假禁用页面。
- 今日：一行投入摘要，周/月为次要入口；左侧主计时与感想，右侧紧凑今日账本及真实7日趋势。开始/暂停/继续/结束按实际状态启用；补录在标题旁、学习记录在账本标题可发现。小窗保留可操作计时和记录，次要区域纵向重排。
- 历程：月历与每日详情先出现，年度热力在后；真实区间时间轴与纯时长记录分开。本日贡献与整次身份可见，感想与当日联动。
- 明细：紧凑行、明确查看/编辑/删除入口；日期/科目/章节/来源/状态筛选；列表虚拟化；详情展示片段、软删除恢复与修订。浮层禁用底层、循环Tab、Escape关闭与焦点返回，防止全局快捷键穿透。
- 统计：行内期间/科目筛选和自定义范围，总投入与两种分母各自明确；每日真实科目堆叠为主，环形与原始记录为辅；周/月趋势、热力及章节投入保留。悬停与键盘精确值、日期/科目下钻不丢筛选。
- 计划：科目/章节树与待办工作区分配空间；进度和掌握状态独立；新增、编辑、归档复用现有流程。
- 薄弱点：搜索与筛选在列表前，名称/科目/章节/错因/复习日/状态有层级；状态分布和历史仍可查，沿用原三状态。
- 设置：档案、主题、计时偏好与数据操作分区；备份/校验/导出/检查清晰，完整恢复采用现有确认和回退，数据路径可读。

资源集中于 ThemeService + Styles.xaml。动态主题颜色用 DynamicResource；固定样式结构用 StaticResource。科目颜色固定映射并配文字，危险与核对分别独立红/赭语义。支持系统高对比色的映射，但真实高对比设备测试单列。

字体：Segoe UI Variable Text/Display，中文 Microsoft YaHei UI；正文14、辅助12、分区18、页标题26、统计32、时钟48（小窗收紧）。数字使用Tabular；不下载商业字体。中文短标签避免孤字换行；长备注限定预览行数并提供完整详情/Tooltip，不截断唯一信息。

间距4/8/12/16/24/32；控件40 DIP最小操作高度，重要操作44；输入8圆角、普通表面12～16。只在表达结构/焦点处用边框，不给每层内容套卡；图标统一原生矢量。主操作实底、次操作轻底/文字、危险操作低饱和红并确认。

时长：内部与统计保留原始毫秒；大字和行预览采用小时/分钟/秒，省略低位时加≈；精确值在Tooltip/明细。禁止1.94小时一类浮点大字替代自然阅读。不重复对聚合取整，不改事实来源。

图表：真实轴、合理刻度、柔和科目色、轻网格、精确提示与清晰命中区域；折线用实际点连接，不平滑虚构值。零值/单点/极端值有明确处理；热力不把无记录当休息。尊重系统动画设置，无日常滚动/计数/图表入场动画。

## Skills 分工与冲突裁决

UI/UX Pro Max为WPF实现与可访问性主指南；Taste用于层级与布局；Impeccable采用Operate审查、密度/字体/状态和有界验收；Make Interfaces Feel Better用于光学对齐、点击面积、等宽数字和状态。Frontend Design、Web Guidelines仅为辅助审查，不同时作为主视觉规则。具体来源、版本、安装和实际使用记录见V02-SKILLS.md。

拒绝CSS/React/Tailwind/GSAP代码、网页hero/营销CTA、强制巨大留白/双套卡/玻璃、默认高级字体已安装，以及引入DI容器/消息框架等与本次视觉任务无关的架构建议。原生XAML与现有业务优先。

## 明确完成标准

两轮集中视觉检查：首次完整实现后一次批量检查七视图×浅深主题、空态、长文本、900×600与1200×800；集中修复后确认一次。发现影响操作或数据的功能缺陷继续定位修复，但不为无关微调循环截图。真实Native窗口与辅助WPF树分开；本机实际DPI与其他缩放渲染分开。

交付必须包含业务回归、实际WPF操作、图表精度/筛选/下钻、浮层键盘隔离、旧库兼容与完整备份恢复、独立发布运行及哈希校验。所有测试仅用owned隔离库，禁止访问真实学习记录。未验证项如实列NOT TESTED，不能据此宣称所有设备正式验收通过。
