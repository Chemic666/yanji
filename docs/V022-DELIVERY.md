# 研迹 V0.2.2

升级前：在旧版导出完整 .yanjibak，校验备份并留一份独立副本；明确退出旧版后完整解压新运行包，双击 YanJi.exe。默认数据目录仍为 %LOCALAPPDATA%\YanJi。本轮只使用全新 artifacts 合成数据，未自动打开真实用户库。V0.2.1 程序、旧包、修正审核证据与恢复标签均保留。

已实现：所有自动学习时长按原值聚合后向下显示整数秒；0–999ms 显示 0 秒，但仍保留记录、学习日与非零图形。Compact 保留长时长的秒贡献。计时器使用总小时 HH:mm，不在 24 小时回绕。日常视图隐藏技术时区，设置与必要异常证据保留。

统计共用日/周/月/自定义范围和科目筛选，三个顶层视图：数据概览（分母明确的 KPI、主科目堆叠图、辅平面科目环、热力和记录入口）；科目与章节（科目对比、含所属科目的章节排行、未指定/归档和关联记录）；学习复盘（独立阶段输入、持久化查看/编辑、软删除恢复、当前薄弱点与复习计划、真实任务、真实每日感想材料）。没有效率评分、历史薄弱点状态推断或虚构本期任务完成量。

章节初始空态及管理入口、科目切换即时刷新、归档禁止新选且已有引用可读。科目/日期/章节下钻保留范围与有效片段，跨日贡献和整次身份分开；DurationOnly 保持独立列表。环形中心采用文本真实高度居中；悬停不描外圈、不放大，键盘提供独立可见提示。

1200×800 主次双栏优先主要数据和动作，900×600 单栏纵向滚动。长范围主图明确按周/月聚合，首尾桶只包含所选日期；热力保留完整十年内范围和年份语义，横向滚动及键盘可达。学习事实、休息标记、无记录和待核对独立；仅已确认前缀计入时长。

阶段复盘使用现有 settings 的 period-review:v1: JSON 命名空间，独立实体/API、范围、可选科目、正文、创建/更新时间和 Version。写入与 revision 共用既有 SQLite 事务，校验解析/版本、编辑冲突、删除恢复和完整备份往返。SQLite schema 仍为 1，没有新表或迁移。

导出边界：CSV 是全量有效记录的逐片段导出，不随统计页范围/筛选变化。保留旧分钟列（最多三位小数，不能作为原始精度来源），新增“精确毫秒”和“显示整数秒”；原始 UTC 区间、备份与审计精度不变。范围 CSV、独立复盘 CSV 和独立复盘历史浏览器未实现；复盘修订保留在完整备份中，阶段文本可以持久化查看/编辑/删除恢复。

交付文件：Source ZIP、win-x64 自包含运行 ZIP、小型 Review ZIP（打开 index.html）、单独 TestEvidence ZIP。外部 sha256.txt、ZIP-EXPECTED.json、ZIP-ENTRY-SHA256.json 与 ZIP-VERIFICATION.json 列出所有关闭 ZIP 内文件的独立 SHA256/大小；截图索引、metadata、HTML 与 provenance 同批校验。程序集 InformationalVersion 的源码 hash 与 source ZIP 的 Git 提交一致。最终状态以 artifacts/v022-completion.json 的实际包装验证结果为准。

已验证与限制见 V022-VALIDATION.md；Skill 本次工具调用和实际采用点见 V022-SKILL-USAGE.md。剩余真实设备验证为 NOT TESTED 项，不影响本轮隔离目录的可运行交付边界。
