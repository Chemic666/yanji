# YanJi V0.4.0 Beta

建议标签：`v0.4.0-beta.1`。本文件为准备好的发行正文，**标签、远程 Release 和附件均尚未创建或上传**；公开前仍需通过隐私及素材许可审核并获得单独授权。Beta 不代表 Stable。

研迹是一款面向考研学生的本地 Windows 学习管理软件，让日常计时、章节进度和学习回顾尽量简单。

## 包含什么

- 今日：自由计时、番茄钟、倒计时、暂停继续、结束保存、手动补录及迷你计时器。
- 学习进度：多级章节、数学/英语/408 参考目录、独立进度记录、任务与薄弱点关联。
- 学习数据：日/周/月投入、学习日历、趋势、科目与章节分布、历史记录下钻、热力和复盘。
- Quiet Focus 2.0「澄境」浅深主题；本地 SQLite、修订历史、完整备份校验恢复与 CSV 导出。

本次发行准备不新增业务功能，不改冻结视觉或数据结构。程序集版本调整为 `0.4.0-beta.1`，继续使用已修补的自包含 .NET / WindowsDesktop 10.0.13；原始有效毫秒、节点 ID、数据目录隔离和备份规则不变。

## Windows x64 安装

适用于 Windows 11 x64。预备附件：

- `YanJi-v0.4.0-beta.1-windows-x64.zip`：程序与必要许可/使用说明，包含运行时。
- `YanJi-v0.4.0-beta.1-source.zip`：对应本地交付提交的完整受控源码树，不含 `.git` 历史。
- `SHA256SUMS.txt`：校验上面两个 ZIP。

这些附件当前仅在本地，**尚未上传到 GitHub**。完整解压到新的可写目录后双击 `YanJi.exe`；无需 SDK 或账号。不覆盖旧安装，不在 ZIP 内直接运行。

```cmd
certutil -hashfile YanJi-v0.4.0-beta.1-windows-x64.zip SHA256
```

核对随包完整哈希；哈希不是代码签名或安全认证。

## 数据与回退

普通启动使用 `%LOCALAPPDATA%\YanJi`，程序移动不会改变数据目录。隔离试用必须明确指定 `--test-mode --data-dir "独立绝对目录"`，无效参数不回退正式目录。仅移动程序不能实现隔离。

**旧版数据库不自动迁移，旧候选 data 目录不自动导入。** Beta 建议新档案试用。遇到旧库不兼容时保留原文件，使用原版程序与对应备份，不直接把旧库复制进新版。

设置中可备份、校验和完整恢复。恢复会替换当前数据，不合并，并保留恢复前备份；CSV 不能替代完整备份。不要复制打开中的SQLite主文件而忽略WAL/SHM。备份未加密。详见 `USER-GUIDE.md` 与 `UPGRADE-ROLLBACK.md`。

## 必须了解的 Beta 限制

- **未代码签名**，SmartScreen 表现尚未实测；不要关闭安全设置来绕过未知警告。
- 物理微软拼音候选输入、Enter / Ctrl+Enter 尚未完整实测。
- 真实睡眠和休眠恢复尚未完整实测；不确定间隙不自动计为有效学习。
- 100% / 125% / 150% DPI、干净 Windows 配置和完全离线首次启动仍有验证缺口；本机200%DPI有既有证据。
- 曾出现偶发约一秒的未归因停顿。没有15秒周期整页重建复发证据，不能声称绝无卡顿。
- 先前约77分钟观察不等于数小时耐久通过；本次仅执行版本与打包相关短验证。
- 数学、英语、408 是自编参考知识目录，**不是官方2028年完整考纲**；没有附带商业教材、题库或讲义正文。请核对当年要求。
- 学习时长、任务完成、章节进度和知识掌握是不同事实，软件不据时长自动宣称掌握。

用户已接受披露这些兼容性限制用于Beta，但这不豁免真实P0/P1数据安全问题。当前没有完成上述物理场景的新增验收，不把模拟或隔离模式写成实机PASS。
