# YanJi V0.4.0

> 本地发布说明草稿，未创建远程Release。Beta/Stable及最终标签由维护者决定；当前程序集仍保留候选版本标识。以下内容在解除发行阻断并获得公开授权后使用。

研迹是一款面向考研学生的本地Windows学习管理工具，关注每天的计时、章节进度和学习数据回顾。无强制账号、服务器或云同步，不要求连续打卡。

## 本次能力

- 今日：自由计时、番茄钟、倒计时、暂停继续、手动补录与悬浮迷你窗。
- 学习进度：数学、英语、408参考目录，多级节点与独立进度记录，任务和薄弱点关联。
- 学习数据：今日/周/月投入、学习日历、趋势、科目分布、章节投入、历史记录、热力和复盘；能追溯原始片段，编辑/软删除/恢复保留历史。
- Quiet Focus2.0「澄境」浅深主题；本地SQLite、完整备份校验与恢复、CSV导出。
- 本轮发行准备把自包含.NET/WindowsDesktop运行时从10.0.12更新到10.0.13，处理微软2026年10月安全公告；业务与冻结视觉不改。

## Windows x64 使用

要求Windows11 x64。下载Windows x64 ZIP及SHA256SUMS.txt，核对哈希后完整解压到新的可写目录，双击YanJi.exe；不需要SDK、账号或网络。不要覆盖旧安装或直接在压缩包内运行。

```cmd
certutil -hashfile YanJi-V0.4.0-Publication-Candidate-windows-x64.zip SHA256
```

比对SHA256SUMS.txt中的完整值；哈希只核对内容，不是代码签名或安全认证。

首次创建档案，选择方向或暂未确定，按需应用参考目录，选择科目即可开始。数学一/二区分范围；英语一/二是复习辅助模块；408包含四门学科的177节点。**不是2028年度官方完整考纲**，请核对当年考试要求。

## 数据与回退

普通启动使用`%LOCALAPPDATA%\YanJi`，不随程序位置改变。隔离试用必须显式使用`--test-mode --data-dir "独立绝对路径"`；不自动迁入旧候选数据或升级旧格式数据库。用户数据不随开源上传。设置与数据可导出/校验完整`.yanjibak`；CSV不能替代完整备份。恢复是完整替换，不合并，操作前保留现有备份。

新候选建议从空档案试用；未授权自动升级真实旧库。保留旧程序及升级前备份，旧程序不能直接打开较新Schema；回退使用升级前数据。详见随包USER-GUIDE.md和UPGRADE-ROLLBACK.md。

## 公开披露的限制

- **未代码签名**，SmartScreen表现尚未验证；不要关闭系统安全功能来绕过未知警告。
- 物理微软拼音与Enter/Ctrl+Enter尚未完成正式兼容性验收。
- 真实睡眠/休眠恢复尚未实机完成；未知间隙不会自动计时。
- 100%/125%/150% DPI与干净Windows离线使用仍有缺口；本机200%已有定向证据。
- 曾观察到偶发约1秒未归因停顿；没有每15秒整页重建复发证据，但不能保证完全无卡顿。
- 约77分钟观察按用户要求缩短，不能写成数小时耐久通过；新的安全运行时仅执行必要短回归，不能继承旧运行时全部实机结论。
- 图标、背景、概念参考及Git历史隐私门禁以发行安全报告为准；未解除时禁止公开本包。
