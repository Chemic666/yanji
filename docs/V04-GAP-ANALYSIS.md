## 2. 必须保留的不变量 [事实+要求]

1. 一次学习一个科目、一个主要节点；不在 V0.4 新增无定义的多节点时长分摊。手动补录仍只有日期/科目/时长必填，节点可空。（S01/S04）
2. 时长只有 sessions/parts 一个事实来源；暂停/休息/未知间隙不制造时长，原始毫秒先汇总。计时不是 UI Tick 累加。（S02/S04/S11）
3. 旧 Chapter ID、session/part ID、Subject ID、日期/时区/时长、版本/软删、Focus 与原修订 JSON 保留。节点删除不得删除学习记录。（S01/S03/S04）
4. 改节点结构不能越过原有同科目规则；已关联科目/档案的身份不能因改名或切档案改写旧记录。（S05）
5. 活动计时仍一个；恢复仍完整替换而非合并；记录修正/片段排除/恢复继续按原事务和重叠检查。（S04/S06）

## 3. 四个语义，不互相推导

| 用户看到的状态 | 事实来源 [建议保留] | 禁止推论 |
|---|---|---|
| 已学习 | 用户填写节点进度；100%标为“自评已学习”；时长另外显示 | 有时长不自动已学；包新增节点不是已学 |
| 完成任务 | LearningTask.Done，用户明确勾选 | 计时结束/目标达成不自动 Done；Done不自动改节点进度 |
| 掌握 | Mastery=Unknown/Weak/Reviewing/Mastered，用户自评 | 进度100%不等于掌握；任务全完成不等于掌握 |
| 验收通过 | 关联 WeakPoint.State=Verified 的显式状态 | “薄弱点已验收”不表示整个知识节点通过考试；无验收数据则显示未记录 |

[建议] V0.4 不新增小测成绩或知识自动验收算法。节点详情显示自评进度、自评掌握、当前任务状态、薄弱点验收分别一栏；不能把四个数字合成“学习效果分”。父节点进度仍可自评，另显示子节点已学数量（明确点数分母、无权重、不含已归档/软删节点），不偷偷取代旧 Progress。

## 4. 需要明确的默认决策 [建议，不是已实现]

- 旧单档案迁入 `legacy-default`，入学年2028，考试日期取旧合法设置（可空）；不猜数学一/英语一，不从入学年推造考试日期。名称注明历史默认档案，已有各科目含归档状态完整保留。
- 支持多个档案但仅一个活动档案；复用全局科目 ID，变体/显示别名放在档案组合。档案有历史记录/目录后不改考试类别和入学年份，要变更目标创建新档案；日期/名称可修订。
- 节点跨科目/档案移动不在 V0.4 实施；复制为新节点可后续评估，不能把旧历史归属静默挪过去。
- 保存过的节点删除是可恢复软删；归档表示暂不用。旧历史仍可查看；“删除目录”不删 sessions/parts。包上游删除不自动抹掉本地节点。
- 默认不按名字合并旧章节与导入节点；名字可以重复（现有 Subject/Chapter 无名字唯一约束）。来源 ID、安装实例才是幂等依据。
- 知识统计按当前目录结构，明确自身/子树口径；新记录保存记录时路径快照，旧记录没有就注明未记录，不补造历史路径。
- 树结构/包写入与迁移/恢复在存在 Running/Paused/NeedsReview 时受限；预览/搜索可继续，学习选择保持冻结。手工进度可短事务写，必须在 M3 验证不会阻塞秒级显示。

## 5. 原有实现需要改的具体缝隙

[事实] SaveChapter 用 INSERT INTO chapters VALUES（6参数），新增列必改为显式列/兼容适配；MainWindow 编辑 Chapter/Task/WeakPoint 重新构造旧 record，新元数据会丢失，不能只给模型追加可空字段就交付。（S05/S10）

[事实] SaveTask/SaveWeakPoint 先检查引用，再调用独立 SaveEntity；V0.4 图结构/导入对引用敏感，要把检查与写入放同一个连接/事务。不要依靠 JSON 存储而省略完整引用检查。（S05）

[事实] SaveTimer 构造 StudyRecord、Completed 重试等价性、durable 快照、CheckAllData 检查点比较都必须传播新学习上下文。只在编辑页加 NodeId，会让自动恢复/幂等校验丢关联。（S04/S07）

[事实] MainViewModel.TickAsync 的 Busy 早退；大树加载若复用全局 Busy，可能再次表现为数字停止刷新。新目录只读操作用自己的加载状态，不阻塞 UI 时钟。（S07/S11）

## 6. 尚未验证

所有 Schema2、知识包合并/回滚、10k 节点性能、V0.4 WPF 渲染均 NOT TESTED。M0 仅有 SQL 内存可行性和历史证据核对；没有真实用户数据库、迁移/替换、实际供电测试。能进入的是隔离 M1 验证与实现，不能把设计文档当成正式升级安全证书。
