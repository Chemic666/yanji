# 研迹 V0.3 使用说明

完整解压 win-x64 包，双击 YanJi.exe。无需安装 .NET、账号或服务器。正式默认学习库仍在 `%LOCALAPPDATA%\YanJi`；本轮开发没有打开此目录。升级前在旧版保存并校验完整备份，再退出旧程序。V0.2.2 和已有小修发布包保留。

今日学习选择自由计时、倒计时或番茄钟。自由计时按实际学习保存；限时模式填写目标分钟，番茄还可填写休息分钟。大数字沿用 HH:mm，旁边自然时长显示剩余秒数和目标。只统计可信有效学习区间，不含暂停、休息或待核对时间。

从今日待办或计划页点击“开始”，自动带入任务科目并保存任务关联。未指定科目时使用当前选择的科目并明确提示；归档科目任务须先调整科目。活动期间不能替换目标或任务。任务完成由你明确标记，计时结束不会自动完成任务。

番茄达到目标会自动保存并进入休息。可以暂停休息、跳过或提前点击“开始下一轮”；下一轮不会自动开始。提前结束专注保存真实已学时长，不虚构目标完成。休息不产生学习记录，应用重启后不继续旧休息倒计时。

迷你窗和主窗共享计时。可选择置顶，关闭迷你窗只是隐藏。活动期间主窗 X 进入托盘；明确退出仍保留“结束保存 / 暂停退出 / 取消”选择。重启若恢复 Running 检查点，未知间隙仍须核对；Paused 保持暂停。

研迹窗口内快捷键：Ctrl+Enter 开始，Ctrl+Space 暂停/继续，Ctrl+M 迷你窗，Ctrl+L 或原 Ctrl+N 补录。文本输入框和选择器不截获启动/暂停；未注册全系统热键。实际键盘、中文输入法和其他显示 DPI 的本轮覆盖边界见验证报告。

已有记录详情、修正、整次软删除、片段排除/恢复、统计联动、完整备份恢复及 CSV 保留。任务与模式是关联元数据，不是新的时长来源。恢复完整备份前先结束活动计时，并按原确认/回退流程操作。本轮没有数据库结构迁移；新关联使用既有设置表并和计时记录一起事务保存。避免用旧程序继续编辑 V0.3 活动计时。

当前仅本地交付 V0.3，不自动推进 V0.4～V1.0，也未公开推送或发布。开源发行文档和最终许可在公开发行前另行审查。
