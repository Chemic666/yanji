# V0.2 两套视觉方向比较

本轮交付可运行 Windows 视觉样板，不是正式 V0.2 六页面版本。两个方向各完成今日学习、统计与复盘、浅色和深色；同一份独立示例数据，复用同一业务实现，便于公平比较。

|维度|A 静桌 · Quiet Desk|B 专注工作台 · Focus Studio|
|---|---|---|
|气质|暖纸色、鼠尾草、安静的学习桌|矿物灰、石板蓝、清晰的工作台|
|导航|176 DIP 文字侧栏，小窗折为图标|64 DIP 图标轨道，顶部提供今日/统计文字页签|
|今日布局|左侧抬升计时区与感想，右侧学习账本与小趋势|左侧紧凑控制台与趋势，右侧较宽日志与感想|
|统计主角|每日科目堆叠；环形占比与时长列表|通栏实际趋势；科目时长条与原始记录预览|
|优势|主次直观，科目结构容易读，适合长期使用|日志宽、导航占地小、趋势突出，查看数据更直接|
|代价|文字侧栏占宽；小窗图例等次要区域需要滚动|图标需要熟悉，整体更理性；科目占比不如环形直接|

**设计建议：采用 A。** 它更符合 Quiet Focus 与“打开即开始、结束即回顾”的学习场景。B 更适合偏爱紧凑工作台和趋势分析的用户。这是设计判断，不是已验证的长期偏好。

采用任意方向都保留精确 Tooltip、原始记录下钻、暂停/核对状态、短时长秒数展示、数据修订与恢复。后续可借用 B 的紧凑明细行，但不在本轮混合两套方案后强行推广。

## 如何比较

1. 运行 `releases/YanJi-v0.2-visual-preview-win-x64/YanJi.DesignLab.exe`；顶部切换 A/B 和深浅主题。
2. 分别打开今日、统计；试用补录、图表下钻、记录备注与软删除/恢复。数据是明确标注的示例，不连接正式数据库。
3. 对照交付目录的 `comparison.html`。它只是离线截图图册；展示的是实际 WPF 窗口 PNG，不是 Web 实现或设计稿。
4. 只需最终选择 A 或 B。收到选择后才把所选设计系统推广到正式六页面。
