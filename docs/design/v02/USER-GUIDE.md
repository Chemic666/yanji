# 双方案样板使用说明

双击 `releases/YanJi-v0.2-visual-preview-win-x64/YanJi.DesignLab.exe`。发布包自带 .NET Windows 运行时，在本机无需安装 SDK；请把整个文件夹一起解压，不要只复制 exe。

顶部切换 A 静桌 / B 工作台、浅色 / 深色。A 侧栏或 B 顶部页签切换今日与统计；其他页面在本轮未实现，导航明确禁用。

今日可选科目和主要章节、开始/暂停/继续/结束、快速补录、保存感想。统计可切换今天、本周、本月、近30日及科目；悬停查看精确时长，点击图表或科目查看对应记录。图表聚焦后 Home/方向键选择、Enter 下钻；浮层可 Escape 关闭。

记录详情显示有效片段、整次与本日贡献、修订历史。样板支持备注修正、整次软删除及恢复；**没有实现新的全量时长编辑界面或片段操作界面**。正式 V0.1.1 原有修正和片段能力仍保留，所选方向推广时复用。

## 数据隔离

默认数据位于 `%LOCALAPPDATA%\YanJiVisualLab\v02`，含 `VISUAL-LAB-ONLY.txt`。首次启动生成明确标注的演示记录；之后在这个示例库内保存操作。不读取 `%LOCALAPPDATA%\YanJi` 正式库，不执行升级迁移或备份恢复。

窗口关闭会暂停并保存样板计时，然后退出；**样板不提供正式应用的托盘流程**。请继续用原 V0.1.1 记录真实备考。不要把真实记录或个人数据库导入样板目录。

自动验收使用新的 GUID 目录，可用 `tools/Invoke-VisualLab.ps1 -Executable <完整 exe 路径>` 复现；每次保留捕获、退出码和断言 JSON。该脚本捕获的是进程自己的 HWND，不截取其他应用。构建辅助工具的便携 SDK 路径是本机环境配置，不影响发布 exe 运行。

## 当前限制

本机真实 200% DPI 已检查；其他 DPI、跨显示器、物理中文 IME 与真实休眠未验证。样板使用软件渲染保证原生窗口捕获稳定，GPU 性能没有验收。此包用于最终视觉选择，不应当作正式 V0.2 更新安装。
