# 研迹 / YanJi

**一款专注于考研日常计时、学习进度记录和学习数据回顾的本地 Windows 桌面软件。**

选择科目，开始学习，记下学到哪里。研迹把学习计划、专注执行、章节进度与复习回顾放在一起，让每天的记录尽量在1～3分钟内完成。

无需账号、服务器或云同步，不强制连续打卡。Quiet Focus 2.0「澄境」使用暖米白、柔和绿色与自然光背景，支持浅色/深色主题和悬浮迷你计时器。

> **发行状态：本地公开发行候选，尚未公开发布。** 正式GitHub仓库地址与Beta/Stable版本号待维护者确认，目前没有公开下载链接。

## 三个日常页面

- **今日**：自由计时、番茄钟、倒计时，支持暂停、继续、结束和补录。科目必选，章节、任务、备注可选。
- **学习进度**：查看数学、英语、408学到哪里、最近学了什么、下一步计划；不计时也能独立保存进度，完整知识树按需展开。
- **学习数据**：今日/本周/本月投入、学习日历、趋势、科目分布、章节投入、热力和复盘直接可见，可下钻原始记录；编辑、删除、恢复保留追溯。

任务、薄弱点、知识包管理、历史修订和备份保留在自然的次级入口。学习时长、章节进度、任务完成和知识掌握互相独立，不用“学了多久”自动判断“已经掌握”。

## 数学、英语与408参考目录

新档案可以选择应用预设目录，已有目录不会静默覆盖；更新预览差异并保护本地修改。

- 数学一/数学二区分适用范围，切换展示不删除历史进度。
- 英语一/英语二区分适用内容，以词汇、语法、长难句、阅读、翻译、写作等复习模块组织，不宣称为官方固定章节。
- 408含数据结构、计算机组成原理、操作系统和计算机网络，共177个参考节点，保留旧145个节点的外部身份。

这些是自编参考目录，**不是2028年度官方完整考纲**，不附商业教材、题库或讲义正文。请自行核对当年考试要求。[适用范围和来源](docs/V04-SIMPLE-REFERENCES.md)

## 下载与运行

支持 **Windows 11 x64**。Windows ZIP包含.NET运行时，普通用户无需安装SDK或配置开发环境。

正式发布且仓库地址核实后，从该仓库Releases下载Windows x64 ZIP，核对随包SHA-256，完整解压到新的可写目录，双击`YanJi.exe`。不要在压缩包内直接运行，也不要覆盖旧安装。

程序目前**未代码签名**，SmartScreen表现未实测。遇到警告时先核对来源与哈希，不要据README认定绝对安全，也不建议关闭系统安全功能。

首次创建考试档案，选择考试方向或暂未确定，按需应用参考目录，选择科目即可开始学习。[使用说明](docs/USER-GUIDE.md)

## 本地数据、隐私与备份

普通启动默认在`%LOCALAPPDATA%\YanJi`保存SQLite数据，与程序位置无关。候选隔离试用必须使用`YanJi.exe --test-mode --data-dir "D:\YanJi-Isolated-Trial"`；解压到另一目录不代表数据已隔离。不会自动迁入`data-rc-quiet`或升级旧库。软件没有应用自建遥测上传、自动云同步或在线AI分析；操作系统、开发工具和用户自行同步目录的行为不在此范围内。

**用户数据属于用户自身，不会因开源而上传或公开。** 完整备份、校验、恢复和CSV导出位于设置与数据入口。恢复是完整替换，不合并；保留恢复前备份。CSV不能代替完整备份，也不要只复制打开中的SQLite主文件而忽略WAL/SHM。

首次公开候选建议新档案试用。本轮未授权、未执行真实数据升级；不要把旧库直接复制进新版。[升级与回退](docs/UPGRADE-ROLLBACK.md)

## 已知限制

- 曾出现一次约1秒未归因调度停顿，不能宣称所有卡顿消除；未观察到15秒检查点伴随整页重建。
- 最近运行观察约77分钟，按用户要求提前结束，不是完整数小时耐久通过。
- 物理微软拼音候选及快捷保存、真实睡眠/休眠、100%/125%/150% DPI、干净机离线、SmartScreen仍有验收缺口。
- 参考目录不保证覆盖所有考试内容，学习投入不等于学习成果。
- 图标、背景和概念参考的权利边界独立核对，不因根LICENSE自动成为已确认原创资源。[素材审查](docs/ASSET-RIGHTS.md)
